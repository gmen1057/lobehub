# Workflow: SEO / спрос

## Бюджет вызовов на один ответ пользователя

Идеал: **1** `get_wordstat_batch` (3–8 фраз).

Допустимо добавить:
- **1** `get_wordstat_dynamics` — если спросили «растёт/падает/сезон»
- **1** `get_wordstat_regions` — если спросили «где крутить / какой город»

Недопустимо: цикл по 20–50 одиночным `get_wordstat`.

## Как выбирать фразы для batch

1. Ядро: 1–2 главные формулировки пользователя  
2. Синонимы: 1–2  
3. Модификаторы: онлайн/очно, город, «цена», «запись» — только релевантные  
4. Отсечь: бренды конкурентов без запроса, мусор, слишком длинные вопросы  

## Регионы

- `225` — Россия (default)
- `213` — Москва
- `2` — Санкт-Петербург

Не дергай все города по отдельности — один `get_wordstat_regions` с level `cities` или `regions`.

## Если лимит сработал

1. Сообщи пользователю: лимит Wordstat, нужно подождать или сузить запрос  
2. Работай с уже полученными цифрами  
3. Не повторяй вызов в цикле  

## Пример хорошего плана

Вопрос: «есть ли спрос на йогу для спины онлайн?»

1. Уточнить гео (если критично)  
2. batch: `йога для спины`, `йога для спины онлайн`, `йога при болях в спине`, `лёжащая йога`, `yoga for back` (если нужен EN)  
3. При необходимости dynamics на топ-1 фразу  
4. Ответ с таблицей и рекомендацией
