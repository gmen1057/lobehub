# Каркас структуры РК (шаблон)

## Поиск — пример

```
Кампания: [Поиск] [Гео] [Продукт]
├── Группа: «ядро + коммерция» (записаться / цена / купить)
│   ├── Ключи: exact/phrase-like кластер
│   ├── Объявления: 2–3 варианта
│   └── Минуса группы: чужие услуги
├── Группа: «информационный → прогрев» (только если есть контент-воронка)
└── Минуса кампании: вакансии, бесплатно (если не оффер), DIY, чужие бренды
```

## РСЯ — пример

```
Кампания: [РСЯ] [Гео] [Продукт]
├── Группа: интересы / ретаргет (если есть)
├── Креативы: оффер + визуал
└── Жёсткие минуса: детский контент / нерелевант (по нише)
```

## Чеклист перед запуском

- [ ] Цель и способ измерения (Метрика / CRM)
- [ ] Лендинг совпадает с объявлением
- [ ] Гео = реальной зоне обслуживания
- [ ] Семантика из Wordstat, не «из головы»
- [ ] Минуса на старте (мусор + вакансии + freebies)
- [ ] Бюджет теста ≥ несколько дней при разумном CPC
- [ ] Не смешивать поиск и сети в одной куче без причины

## Что смотреть через 3–7 дней

- Расход, клики, CTR (гигиена)
- Конверсии / CPL (главное)
- Поисковые запросы → новые минуса и новые группы
- Где сливается: ключ / площадка / объявление / лендинг
